Qui je suis ?

Passionné par les innovations technologiques, j'ai choisi de m'orienter vers le BTS Services Informatiques aux Organisations (SIO), option SLAM. Cette formation me permet de maîtriser la conception et le développement de solutions logicielles et web répondant aux besoins critiques des entreprises. Actuellement en deuxième année, je consolide mes compétences techniques afin d'évoluer vers un profil de développeur Full Stack, avec l'ambition de piloter des projets de bout en bout.

Projets


Lors de mes années de BTS, la réalisation de plusieurs projets m'a permis de développer mes compétences techniques et de me familiariser avec les outils professionnels. Je vais vous en présenter quelques-uns.

Projet Aunis Freeware :

Ce projet devait être réalisé en équipe de deux sur Visual Studio Code en HTML/CSS et en PHP. L'objectif était de créer un site web pour une association fictive nommée Aunis Freeware, avec un cahier des charges précis. Le site devait inclure des fonctionnalités telles qu'une page d'accueil, une page de présentation de l'association, une galerie d'images, une section pour les actualités, et un formulaire de contact.

Projet CDM :

Ce projet devait être réalisé seul avec Symfony. Ce projet avait pour objectif de créer une application web de gestion d'une coupe du monde de football. Projet Echappee :

Ce projet fait partie des deux projet finaux pour l'epreuve E6 pour le BTS SIO réaliser en équipe. Ce projet consiste à concevoir une application mobile Android sur Android Studio en Java centralisant le patrimoine touristique de la Charente pour les étudiants, touristes et enseignants. L'objectif est de faciliter la découverte du territoire via des itinéraires personnalisés et des fonctionnalités sociales, tout en intégrant de sensibilisation à l'accessibilité. Sur le plan technique, le développement repose sur une architecture robuste comprenant un backend API REST, une base de données d'au moins six entités, l'utilisation d'Open Data local et un système d'authentification sécurisé, le tout géré en équipe via Git avec une exigence de fonctionnement en mode hors connexion.

Projet ChronosFormation :

Ce projet fait partie des deux projet finaux pour l'epreuve E6 pour le BTS SIO réaliser en équipe. Ce projet vise à concevoir une plateforme de gestion de formations structurée autour de trois profils utilisateurs (stagiaire, formateur et administrateur), chacun disposant d'un espace dédié. Tandis que les stagiaires peuvent consulter le catalogue et s'inscrire à un parcours de une à six formations, les formateurs gèrent leurs assignations et leurs disponibilités pour le tutorat, le tout étant supervisé par un administrateur centralisant la création de comptes et la planification pédagogique. Ce projet a étais réalisé sur Visual Studio Code avec Symfony.

Veille Informationnelle

Dans le cadre de mon projet professionnel, j'ai choisi de réaliser ma veille sur l'impact de l'IA sur les métiers du développement logiciel. Étant futur développeur, il est essentiel pour moi de comprendre comment ces outils transforment nos méthodes de travail, de l'écriture du code jusqu'à la phase de test. Cette veille m'a permis d'analyser l'évolution des compétences attendues : si l'IA automatise les tâches répétitives, elle renforce l'importance de l'architecture et de la cybersécurité. En suivant ces évolutions, mon objectif a été de me renseigner afin de mieux adapter mon apprentissage pour maîtriser ces nouveaux outils de productivité. Cela a été pour moi un moyen concret de préparer mon employabilité et d'anticiper les possibles transformations du marché de l'informatique.
